# App Privacy回答案

この回答はGoogle Mobile Ads 13.7.0のPrivacy Manifestと、Yohakuの問い合わせ実装を含めた保守的な案です。Archiveから生成したPrivacy Reportおよび提出時点のGoogle開示資料と最終照合してください。

- Data Collection: `Yes`
- Tracking: `Yes`
- Privacy Policy URL: `https://yohaku.tmkch.io/privacy`
- User Privacy Choices URL: `https://yohaku.tmkch.io/privacy`

## データタイプ

| App Store項目 | 用途 | ユーザーにリンク | トラッキング | 出所 |
|---|---|---:|---:|---|
| Name | App Functionality（任意の問い合わせ） | Yes | No | Yohaku Support |
| Email Address | App Functionality（問い合わせ返信） | Yes | No | Yohaku Support |
| Customer Support | App Functionality | Yes | No | Yohaku Support |
| User ID | App Functionality（ランダムなサポートID） | Yes | No | Yohaku Support |
| Coarse Location | Third-Party Advertising / Analytics / Developer Advertising | Yes | No | Google Mobile Ads / UMP |
| Device ID | Third-Party Advertising / Analytics / Developer Advertising | Yes | Yes | Google Mobile Ads |
| Product Interaction | Third-Party Advertising / Analytics / Developer Advertising | Yes | No | Google Mobile Ads / UMP |
| Advertising Data | Third-Party Advertising / Analytics / Developer Advertising | Yes | No | Google Mobile Ads |
| Crash Data | Analytics | No | No | Google Mobile Ads |
| Performance Data | Advertising / Analytics | No | No | Google Mobile Ads / UMP |
| Other Diagnostic Data | Advertising / Analytics | No | No | Google Mobile Ads |

ATTを許可した場合だけ、Device IDを他社のアプリやWebサイトをまたぐ広告・測定に使用できます。拒否時もIDFAなしの広告が表示される場合があります。

問い合わせ情報は任意のカスタマーサポート入力としてAppleの任意開示条件に該当する可能性がありますが、初回提出では透明性を優先して開示する案です。
